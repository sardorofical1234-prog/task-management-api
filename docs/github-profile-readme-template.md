## Featured project

### Task Management API

A Spring Boot REST API for personal task management and project collaboration.

- JWT authentication and BCrypt password hashing
- USER / ADMIN roles and ownership-based authorization
- Task CRUD, pagination, sorting, filtering and search
- Projects, membership, task assignment and comments
- PostgreSQL 17 with Flyway migrations
- Java tests, Testcontainers, Docker Compose and Newman API tests in GitHub Actions

**Tech stack:** Java 21, Spring Boot 3.5.16, Spring Security, Spring Data JPA, PostgreSQL, Flyway, Maven, JUnit 5, Mockito, Testcontainers, Docker, GitHub Actions and Newman.
